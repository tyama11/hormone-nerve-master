# ホルモン・神経マスター

生物基礎の「ホルモン・自律神経・体内環境」を楽しくマスターできる学習アプリです。

- **かんたん・ふつうモード**: カードを正しい図の枠にドラッグ＆ドロップまたはクリックで配置して仕組みをマスター！
- **おにモード**: 制限時間内に次々出題される問いに答えてランキング（S〜Dランク）に挑戦！
- **豊富なカテゴリ**: 血糖値やホルモン分泌、自律神経のバランスなどを分かりやすい図解とアニメーションで学べます。
